agent.jsonTop level

agent.json — lives next to the executable and is re-read on every request, so edits apply immediately. Names are matched without regard to case.

Portnumberdefault 9443

TCP port the agent listens on (HTTPS). Changing it needs a service restart, and the firewall rule opened by install only covers the port given at install time.

"Port": 9443
ApiKeyHashstringdefault ""

SHA-256 (hex) of the API key. The key itself is only shown once, by "install" or "newkey".

"ApiKeyHash": "9F2C…64 hex characters…A1"      // written by install / newkey
AllowedIpsarray of stringsdefault []

Optional list of client IPs allowed to connect. Empty = any.

"AllowedIps": [ "192.168.1.50", "10.0.0.12" ]
TlsPfxstringdefault "agent-tls.pfx"

File name of the agent's own TLS certificate, next to the executable. Created on first start.

"TlsPfx": "agent-tls.pfx"
TlsPasswordstringdefault ""

Password of TlsPfx. Written by the agent; leave it alone. If it does not open the PFX (for example after copying the example file over agent.json), the agent makes a new TLS certificate and the app asks you to trust the new fingerprint.

"TlsPassword": "(created automatically)"
KeepBackupsnumberdefault 5

How many earlier versions of each destination's files to keep in backups/. 0 turns backups off.

"KeepBackups": 5
Slotsarray of Slotdefault []

The slots this agent offers. An app deployment target names exactly one of them.

"Slots": [ { "Name": "example-com", "Destinations": [ … ] } ]

Slot

What a certificate from the app maps to on this server: one or more destinations. An entry of Slots.

Namestringdefault ""

The name the app's deployment target uses. Matched without regard to case; must be unique in the file.

"Name": "reddin-wildcard"
Descriptionstringdefault ""

Free text shown in the app when you click Connect & list slots.

"Description": "*.example.com for NetTalk and TSplus"
Destinationsarray of Destinationdefault []

Where this certificate goes on this server, processed in order.

"Destinations": [ { "Name": "Web app", "Folder": "C:\\Apps\\Web\\certificates", "Files": [ … ] } ]
Commandsarray of stringsdefault []

Commands run once after all destinations were written and their services restarted.

"Commands": [ "systemctl reload nginx" ]

Destination

One program that uses the certificate. An entry of a slot's Destinations.

Namestringdefault ""

Label used in the app's activity log, in agent.log and as the backup folder name. Falls back to Folder when empty.

"Name": "NetTalk - Portal"
Kindstringdefault "Files"

"Files" (default): write the files below into Folder. "TSplus": import a PFX with TSplus's CertificateManager (TSplus 15+). "TSplusJks": write cert.jks into TSplus\Clients\webserver and restart the TSplus web server (versions that use cert.jks).

"Kind": "TSplus"
TsplusCertFolderstring, optionaldefault none

TSplus only: its cert folder (default C:\Program Files (x86)\TSplus\UserDesktop\files\cert).

"TsplusCertFolder": "D:\\TSplus\\UserDesktop\\files\\cert"
TsplusFolderstring, optionaldefault none

TSplusJks only: TSplus install folder (default C:\Program Files (x86)\TSplus).

"TsplusFolder": "D:\\TSplus"
Folderstringdefault ""

Target folder for Files. Created if it does not exist. Replaces {folder} in this destination's Commands.

"Folder": "C:\\Apps\\Portal\\certificates"
Filesarray of FileSpecdefault []

The files to write, each a source and the file name to give it.

"Files": [ { "Source": "fullchain", "FileName": "portal.crt" }, { "Source": "key", "FileName": "portal.key" } ]
RestartServicesarray of stringsdefault []

Windows service names (or systemd units on Linux) restarted after the files are written.

"RestartServices": [ "PortalWeb" ]
RestartProgramsarray of ProgramSpecdefault []

Windows only: desktop programs (.exe) to close and start again on the same user's desktop.

"RestartPrograms": [ { "Path": "C:\\Apps\\Api\\ApiServer.exe" } ]
Commandsarray of stringsdefault []

Commands run after the files are written (cmd.exe on Windows, /bin/sh on Linux).

"Commands": [ "haproxy -c -f /etc/haproxy/haproxy.cfg && systemctl reload haproxy" ]

File entry

An entry of a destination's Files.

Sourcestringdefault ""

combined, combined-keyfirst, fullchain, fullchain-root, cer, crt, der, chain, key, encrypted-key, pfx, p12, p7b, k8s, jks

{ "Source": "combined", "FileName": "example.com.pem" }
FileNamestringdefault ""

Name of the file in Folder. An existing file is backed up, then replaced atomically.

{ "Source": "key", "FileName": "www.example.com.key" }

Program entry

A desktop program (not a service) to restart after the certificate files were written. An entry of a destination's RestartPrograms. Windows only.

Pathstringdefault ""

Full path of the .exe.

{ "Path": "C:\\Apps\\Api\\ApiServer.exe" }
Argumentsstringdefault ""

Arguments used only when the program was not running (otherwise each instance keeps its own command line).

{ "Path": "C:\\Apps\\Api\\ApiServer.exe", "Arguments": "/port=8443" }
WorkingFolderstring, optionaldefault none

Working folder for the new process; default = the exe's folder.

{ "Path": "C:\\Apps\\Api\\ApiServer.exe", "WorkingFolder": "C:\\Apps\\Api\\data" }
StopTimeoutSecondsnumberdefault 20

Seconds to wait for a normal close before the process is ended forcefully.

{ "Path": "C:\\Apps\\Api\\ApiServer.exe", "StopTimeoutSeconds": 45 }
StartInstringdefault "SameSession"

SameSession (default): restart on the desktop it was running on (or the console if it was not running). Console: always on the console user's desktop. Background: session 0 as the agent's account (no desktop).

{ "Path": "C:\\Apps\\Api\\ApiServer.exe", "StartIn": "Background" }

ValuesAllowed values

File sources

The values check accepts for Source. Sources marked secret contain the private key and are written with mode 600 on Linux when new.

SourceFormatContents
combinedsecretPEMFull chain and private key in one file. HAProxy, Cockpit .cert, Webmin, appliances.
combined-keyfirstsecretPEMPrivate key first, then the full chain. Postfix, lighttpd, Pound.
fullchainPEMCertificate followed by the intermediates. What nginx, Apache 2.4.8+, NetTalk and most servers want as the certificate file.
fullchain-rootPEMFull chain plus the ISRG root, for devices that validate the whole chain.
cerPEMCertificate only.
crtPEMCertificate only, the same bytes as cer.
derbinaryCertificate only, DER encoded. Java and some Windows tools.
chainPEMIntermediates only. Apache SSLCertificateChainFile.
keysecretPEMPrivate key (PKCS#8 or traditional, as chosen in the app).
encrypted-keysecretPEMPrivate key encrypted with the certificate's PFX password.
pfxsecretPKCS#12Certificate, chain and key, protected with the certificate's PFX password. IIS, Exchange, Windows.
p12secretPKCS#12The same as pfx with a .p12 extension. Java/Tomcat, macOS.
p7bPKCS#7Certificate and chain, no key.
k8ssecretYAMLKubernetes kubernetes.io/tls Secret.
jkssecretJava KeyStoreKey and full chain; password from the app's Settings (default secret, which TSplus requires).

Command lineCommands

Run from the agent's folder, as administrator on Windows or with sudo on Linux. Without a command the agent runs in the console, as run does.

install [port]

Create agent.json, API key and TLS certificate, register and start the service.

Creates agent.json (keeping an existing one), a new API key when there is no valid one, the TLS certificate, registers and starts the service and, on Windows, opens the firewall. Safe to run again, for example after moving the executable.

.\CertificateGet.Agent.exe install 9443
uninstall

Stop and remove the service (keeps agent.json).

Stops and removes the service and the firewall rule. agent.json, the TLS certificate and the backups stay.

sudo ./CertificateGet.Agent uninstall
newkey

Generate a new API key (the old one stops working).

Replaces the API key. Enter the new key in every app target that uses this agent. No restart needed.

.\CertificateGet.Agent.exe newkey
info

Show URL, TLS fingerprint and configured slots.

Prints the URL, the TLS fingerprint to compare with the app, the allowed IPs and, per slot, the sources it needs.

sudo ./CertificateGet.Agent info
check

Validate agent.json (folders, services, file types).

Validates agent.json: JSON syntax, API key, IPs, duplicate slots, folders, sources, services, programs, TSplus paths. Exit code 0 when clean.

.\CertificateGet.Agent.exe check
run

Run in this console (default).

Runs in the console with the log on screen. Stop the service first, since both want the same port.

sudo ./CertificateGet.Agent run

ProtocolHTTP API

What the app sends. Every request needs the X-Api-Key header and must come from an allowed IP. Errors come back as { "error": "…" } with status 401 (key), 403 (IP), 404 (slot) or 500 (agent.json unreadable).

GET/api/slots

Lists the slots. Used by Connect & list slots.

{ "host": "WEB01", "version": "1.0.0.0",
  "slots": [ { "name": "reddin-wildcard", "description": "…", "destinations": 3 } ] }
GET/api/slots/{name}

The sources a slot needs, so the app builds and sends exactly those. 404 when the slot does not exist.

{ "name": "reddin-wildcard", "files": [ "fullchain", "key", "pfx" ] }
POST/api/deploy

Runs a deployment. The body is a DeployRequest; the answer lists every step.

{ "success": true, "error": null,
  "steps": [ { "ok": true, "message": "NetTalk - Portal: wrote portal.crt, portal.key to D:\\Portal\\certs" },
             { "ok": true, "message": "Restarted service PortalWeb" } ] }

Deploy request

The body of POST /api/deploy. Property names are camel-case on the wire.

slotstringdefault ""

Slot to deploy to.

"slot": "reddin-wildcard"
certificateCertInfo, optionaldefault none

Name, domains, thumbprint and expiry, used for the log.

"certificate": { "name": "reddin wildcard", "domains": [ "*.reddinassessments.com" ], … }
pfxPasswordstring, optionaldefault none

The certificate's PFX password from the app. Sent only when the slot needs pfx, p12 or encrypted-key.

"pfxPassword": "only-when-a-pfx-is-needed"
filesobject (name → string)default {}

Source name → file contents in Base64. Exactly the sources the slot asked for.

"files": { "fullchain": "LS0tLS1CRUdJTi…", "key": "LS0tLS1CRUdJTi…" }

Certificate info

The certificate object inside the request.

namestringdefault ""

Display name of the certificate in the app.

"name": "reddin wildcard"
domainsarray of stringsdefault []

Every domain on the certificate.

"domains": [ "*.reddinassessments.com", "reddinassessments.com" ]
thumbprintstringdefault ""

SHA-1 thumbprint of the issued certificate.

"thumbprint": "3A7F…"
notAfterdate-time string

Expiry date.

"notAfter": "2026-12-26T10:14:07Z"
