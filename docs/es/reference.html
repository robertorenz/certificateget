La aplicaciónFormatos de archivo

Todos los formatos que la aplicación puede escribir, leídos de CertificateStore.cs. name es el primer dominio. Los formatos Siempre se escriben en cada emisión; los Predeterminado están marcados en Settings hasta que usted los cambie; los Opcional se escriben si se marcan en Settings, o con Export. Los formatos que necesitan contraseña usan la contraseña PFX del certificado.

ArchivosFormatoContenido y usoSe escribe

La aplicaciónMétodos de validación

MétodoCuándo usarloNecesita
HTTP (built-in server)Ejecute la aplicación en el servidor al que apunta el dominio. Responde en el puerto 80 unos segundos, sin IIS.El puerto 80 libre en este PC y accesible desde internet. No requiere permisos de administrador.
HTTP (web root)Un servidor web (IIS, Apache, nginx) ya sirve el sitio. La aplicación escribe el archivo del desafío en su carpeta.Permiso de escritura en la carpeta raíz del sitio, local o ruta UNC. Añade un web.config para IIS.
DNS (manual)Funciona en cualquier caso, también con comodines. Usted crea los registros TXT; la aplicación los comprueba antes de validar.Acceso al panel DNS en cada solicitud y renovación.
DNS (Cloudflare)Crea y elimina los registros TXT mediante la API de Cloudflare.Un token de API con Zone Read y DNS Edit.
DNS (Hostinger)Crea y elimina los registros TXT mediante la API de Hostinger.Un token de API de hPanel; el dominio en los servidores DNS de Hostinger.
DNS (Constellix)Crea y elimina los registros TXT mediante la API de Constellix (v4).Una clave de API y una clave secreta; el reloj del PC en hora.
DNS (acme-dns)Funciona con cualquier proveedor DNS. Un CNAME por dominio y después ningún cambio de DNS ni credenciales DNS en este PC.Un servidor acme-dns (público o propio) y un CNAME para _acme-challenge.
DNS (DNS Made Easy)Crea y elimina los registros TXT mediante la API de DNS Made Easy (v2.0).Una clave de API y una clave secreta; el reloj del PC en hora.
DNS (Namecheap)Crea y elimina los registros TXT mediante la API de Namecheap; todos los demás registros se vuelven a escribir sin cambios.Acceso a la API activado y la IPv4 pública de este PC en la lista blanca.

agent.jsonNivel superior

agent.json: está junto al ejecutable y se vuelve a leer en cada solicitud, así que los cambios se aplican de inmediato. Los nombres se comparan sin distinguir mayúsculas.

Portnúmeropredeterminado 9443

Puerto TCP en el que escucha el agente (HTTPS). Cambiarlo requiere reiniciar el servicio, y la regla de firewall que abre install solo cubre el puerto indicado al instalar.

"Port": 9443
ApiKeyHashcadenapredeterminado ""

SHA-256 (hex) de la clave de API. La clave en sí solo se muestra una vez, con install o newkey.

"ApiKeyHash": "9F2C…64 hex characters…A1"      // written by install / newkey
AllowedIpsarreglo de cadenaspredeterminado []

Lista opcional de IP de clientes que pueden conectarse. Vacía = cualquiera.

"AllowedIps": [ "192.168.1.50", "10.0.0.12" ]
TlsPfxcadenapredeterminado "agent-tls.pfx"

Nombre del archivo del certificado TLS propio del agente, junto al ejecutable. Se crea en el primer arranque.

"TlsPfx": "agent-tls.pfx"
TlsPasswordcadenapredeterminado ""

Contraseña de TlsPfx. La escribe el agente; no la modifique. Si no abre el PFX (por ejemplo, después de copiar el archivo de ejemplo sobre agent.json), el agente crea un certificado TLS nuevo y la aplicación le pide confiar en la nueva huella digital.

"TlsPassword": "(created automatically)"
KeepBackupsnúmeropredeterminado 5

Cuántas versiones anteriores de los archivos de cada destino se conservan en backups/. 0 desactiva las copias de seguridad.

"KeepBackups": 5

Línea de comandosComandos

Se ejecutan desde la carpeta del agente, como administrador en Windows o con sudo en Linux. Sin comando, el agente se ejecuta en la consola, igual que run.

install [port]

Crea agent.json, la clave de API y el certificado TLS, registra e inicia el servicio.

Crea agent.json (conservando uno existente), una nueva clave de API cuando no hay una válida y el certificado TLS; registra e inicia el servicio y, en Windows, abre el firewall. Se puede volver a ejecutar sin riesgo, por ejemplo tras mover el ejecutable.

.\CertificateGet.Agent.exe install 9443
uninstall

Detiene y elimina el servicio (conserva agent.json).

Detiene y elimina el servicio y la regla de firewall. agent.json, el certificado TLS y las copias de seguridad se conservan.

sudo ./CertificateGet.Agent uninstall
newkey

Genera una nueva clave de API (la anterior deja de funcionar).

Reemplaza la clave de API. Escriba la nueva clave en cada objetivo de la aplicación que use este agente. No hace falta reiniciar.

.\CertificateGet.Agent.exe newkey
info

Muestra la URL, la huella TLS y los slots configurados.

Muestra la URL, la huella TLS para comparar con la aplicación, las IP permitidas y, por slot, los orígenes que necesita.

sudo ./CertificateGet.Agent info
check

Valida agent.json (carpetas, servicios, tipos de archivo).

Valida agent.json: sintaxis JSON, clave de API, IP, slots duplicados, carpetas, orígenes, servicios, programas, rutas de TSplus. Código de salida 0 si todo está bien.

.\CertificateGet.Agent.exe check
run

Se ejecuta en esta consola (predeterminado).

Se ejecuta en la consola con el registro en pantalla. Detenga antes el servicio, porque ambos usan el mismo puerto.

sudo ./CertificateGet.Agent run

ProtocoloAPI HTTP

Lo que envía la aplicación. Cada solicitud necesita el encabezado X-Api-Key y debe venir de una IP permitida. Los errores vuelven como { "error": "…" } con estado 401 (clave), 403 (IP), 404 (slot) o 500 (agent.json ilegible).

GET/api/slots

Lista los slots. Lo usa Connect & list slots.

{ "host": "WEB01", "version": "1.0.0.0",
  "slots": [ { "name": "reddin-wildcard", "description": "…", "destinations": 3 } ] }
GET/api/slots/{name}

Los orígenes que necesita un slot, para que la aplicación genere y envíe exactamente esos. 404 si el slot no existe.

{ "name": "reddin-wildcard", "files": [ "fullchain", "key", "pfx" ] }
POST/api/deploy

Ejecuta un despliegue. El cuerpo es un DeployRequest; la respuesta enumera cada paso.

{ "success": true, "error": null,
  "steps": [ { "ok": true, "message": "NetTalk - Portal: wrote portal.crt, portal.key to D:\\Portal\\certs" },
             { "ok": true, "message": "Restarted service PortalWeb" } ] }
